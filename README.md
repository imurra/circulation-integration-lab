# Circulation Integration Lab

KIFS cardiovascular physiology, Activity 4 (Integration). Students work two cases, blood loss and widespread arteriodilation, on a closed-loop veins–heart–arteries diagram:

Two steps per case, each laid out as a flowchart in order of occurrence. Students mark ↑/↔/↓ for every item, then press Next to check; feedback (green/red with rationale) appears only after checking.

1. Because (before reflexes): the immediate snapshot, within a heartbeat or two of the change, before the baroreceptor reflex responds; place X′ on the Frank-Starling curve
2. Baroreceptor reflex: firing → autonomic outflow → effectors → CO → MAP

A 10-minute clock (starts on the first answer) and a scorecard run across the top. Revealed answers and answers checked after time is up do not score.

- `index.html`: current build (Nov 5, 2026), revised after physiology team feedback
- `v3/index.html`: Nov 5, 2026 build, archived before the Nov 11 classroom touch-screen layout fix (smaller diagram, wider question column, compact spacing so each step fits on one screen)

- `v1/index.html`: earlier build (Oct 31, 2026), numbers shown throughout

Values come from a simple teaching model (SV = contractility × Frank-Starling curve; CO = HR × SV; MAP ≈ CO × SVR) and show direction and relative size, not clinical numbers.
